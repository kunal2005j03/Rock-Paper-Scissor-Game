# 🎮 Rock Paper Scissors Game

An interactive Rock Paper Scissors game built using Python and Pygame with a graphical interface, sound effects, animations, and score tracking.

---

## 📌 Features

✅ Modern graphical interface  
✅ Background music support  
✅ Sound effects  
✅ Animated visual elements (GIFs)  
✅ Real-time score tracking  
✅ Interactive gameplay  
✅ Executable (.exe) version available  
✅ Smooth user experience

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/kunal2005j03/Rock-Paper-Scissor-Game.git
```

Move into the project directory:

```bash
cd Rock-Paper-Scissor-Game
```

Install dependencies:

```bash
pip install pygame
```

Run the game:

```bash
python main.py
```

---

## 🎯 How To Play

1. Launch the game
2. Select Rock, Paper, or Scissors
3. The computer randomly chooses its move
4. The game determines the winner
5. Scores update automatically

Rules:

- Rock defeats Scissors
- Scissors defeats Paper
- Paper defeats Rock
